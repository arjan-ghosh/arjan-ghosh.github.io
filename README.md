# Arjan Ghosh - Portfolio Website

Static academic portfolio built from Arjan Ghosh's CV. Plain HTML, CSS and JavaScript. No build tools needed.

## Files

- `index.html` - all page content
- `styles.css` - all styling
- `script.js` - menu, dark mode, scroll effects, count-up numbers, tabs
- `assets/arjan.jpg` - profile photo

## Run on your PC

Double-click `index.html`, or in VS Code install the "Live Server" extension, right-click `index.html` and choose "Open with Live Server".

## Put it live with GitHub Pages

1. The repository is `arjan-ghosh/arjan-ghosh.github.io` (public).
2. Upload every file and the `assets` folder (Add file > Upload files), then commit.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`, Save.
4. After 1-2 minutes the site is live at `https://arjan-ghosh.github.io/`

## Update later

Edit the files, then in the VS Code terminal run:

```
git add .
git commit -m "update"
git push
```
